# 开源发布清单

这份清单用于把长布整理成一个适合公开仓库展示的项目。

## 必做项

### 1. 许可证

当前仓库还没有 `LICENSE` 文件。

在公开发布前，需要先明确：

- 是否允许商业使用
- 是否允许闭源二次分发
- 是否要求修改后继续开源

在这些问题没有明确之前，不建议我替你自动选定许可证。

### 2. README 最终版

公开发布前建议补齐：

- 1~3 张产品截图
- 一段 30 秒以内的 GIF / 视频演示
- 一套可公开复现的 API 配置示例
- 当前已知限制与 roadmap

### 3. 仓库清理

发布前检查以下内容没有进入版本库：

- 真实 API Key
- 本地数据库
- 本地附件目录
- Electron 用户数据目录内容
- 临时测试脚本或个人路径

### 4. 发布说明

建议首个公开版本至少说明：

- 项目定位
- 当前完成度
- 已验证的平台
- 未完成功能
- 适合谁试用，暂时不适合谁

## 推荐但可后补

- issue 模板
- PR 模板
- 截图目录
- demo 数据集
- FAQ

## 当前状态评估

从代码和现有文档看，长布已经具备“可公开展示 MVP”的基础，但还缺两个关键对外材料：

1. 正式许可证
2. 更完整的 README 演示素材

所以当前更适合的状态描述是：

> 已具备开源整理基础，待补许可证与展示素材后可公开发布。
